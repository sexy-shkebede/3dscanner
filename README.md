# 3D Сканер

Android‑приложение для 3D‑сканирования камерой телефона. Это фотограмметрия «на ходу»: пока вы записываете видео и обходите объект, на экране в реальном времени растёт цветная карта точек. После записи карта собирается в полигональную модель прямо на устройстве и экспортируется в GLB / PLY / OBJ.

Интерфейс сделан на Jetpack Compose в стиле **Material 3 Expressive**: `MaterialExpressiveTheme` с экспрессивной анимацией, `LargeFlexibleTopAppBar`, плавающие панели `HorizontalFloatingToolbar`, связанные группы кнопок (`ButtonGroup` / `ToggleButton`), `LoadingIndicator` и `LinearWavyProgressIndicator`, формы `MaterialShapes` и кнопка записи с морфингом формы (cookie → квадрат).

## Возможности

- **Живая карта точек.** ARCore отслеживает положение камеры, а каждый кадр глубины (Raw Depth API с фильтрацией по уверенности, сглаженная глубина или, на устройствах без Depth API, точки‑признаки) проецируется в мир, окрашивается по кадру камеры и сливается в воксельную карту. Новые точки потоково дозагружаются в GPU и рисуются поверх изображения камеры.
- **Запись видео.** Во время сканирования пишется MP4 (ARCore Recording API: видео + данные IMU и позы). Видео можно посмотреть, а скан — **пересобрать из видео** с другими настройками.
- **Сборка модели на телефоне:** фильтрация шума → нормали методом PCA → неявная поверхность IMLS на разреженной сетке → извлечение сетки Surface Nets → удаление мелких фрагментов → сглаживание Taubin → перенос цвета.
- **Просмотрщик 3D:** вращение, масштаб, панорамирование, режимы «точки / цветная модель / глина / каркас».
- **Экспорт:** GLB (glTF 2.0), PLY (бинарный, с цветами и нормалями), OBJ (с цветами вершин) — «Поделиться» или «Сохранить файл».
- Подсказки при плохом освещении, быстром движении и потере трекинга; настройки разрешения карты, дальности, порога уверенности, лимита точек.
- Русская и английская локализации, динамические цвета Android 12+.

## Требования

- Android 8.0+ (API 26) с поддержкой ARCore и установленными «Сервисами Google Play для AR».
- Для плотной карты нужна поддержка ARCore Depth API (большинство современных телефонов). Без неё используется режим точек‑признаков.

## Сборка

```bash
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # юнит‑тесты ядра реконструкции и экспорта
```

Нужны JDK 17+ и Android SDK с платформой `android-37.0`. Если в корне есть `keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`), релиз подписывается этим ключом, иначе — debug‑ключом, чтобы APK можно было сразу установить.

GitHub Actions (`.github/workflows/android.yml`) на каждый push в `main` прогоняет тесты, собирает APK и публикует его в Releases.

## Как пользоваться

1. «Новый скан» → разрешите доступ к камере.
2. Плавно поводите телефоном, пока не начнётся отслеживание (появятся белые точки).
3. Нажмите кнопку записи и медленно обойдите объект с разных сторон и высот. Карта точек растёт на экране.
4. Остановите запись — скан сохранится и откроется просмотрщик.
5. «Собрать модель» (кнопка ✨) → выберите детализацию и сглаживание.
6. «Экспорт» → формат и «Поделиться» / «Сохранить файл».

## Архитектура

```
app/src/main/java/com/scanner3d/
├── core/          чистый Kotlin, покрыт юнит‑тестами
│   ├── PointMap.kt              воксельная карта: слияние наблюдений, буфер для живой отрисовки
│   ├── DepthIntegrator.kt       кадр глубины/признаков → точки мира с нормалями и цветом (YUV)
│   ├── SurfaceReconstructor.kt  IMLS + Surface Nets, очистка, перенос цвета
│   ├── NormalEstimator.kt       PCA‑нормали (Якоби 3×3)
│   ├── MeshOps.kt               нормали вершин, сглаживание Taubin
│   ├── SpatialGrid.kt           поиск соседей, параллельные циклы, прогресс/отмена
│   └── ThumbnailRenderer.kt     программный рендер превью
├── io/            форматы хранения и экспорт GLB / PLY / OBJ
├── ar/            ARCore‑сессия, запись видео, рендер фона камеры и живых точек (GLES 3)
├── gl/            просмотрщик моделей: орбитальная камера, рендер сетки/точек, MSAA
├── data/          хранилище сканов и настройки
└── ui/            Compose‑экраны: главная, сканирование, просмотр, настройки
```

Каждый скан хранится в `files/scans/<id>/`: `meta.json`, `cloud.bin`, `mesh.bin`, `video.mp4`, `thumb.png`.
